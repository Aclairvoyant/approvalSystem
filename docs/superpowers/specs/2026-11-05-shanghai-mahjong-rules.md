# 上海麻将（百搭 / 敲麻）规则默认值

状态：**已确认**（2026-11-05）。所有数值在后端做成可配置常量（`service/mahjong/MahjongRules.java`）。

参考：shen021 敲麻 / 百搭规则页、维基「上海麻将」、知乎与上海市民政局对敲麻的介绍。各平台规则不一致，下表以任务简报为准，参考里不一致或简报没写到的地方单独列在最后「需要拍板」。

## 一、两种玩法共用

| 项目 | 默认 |
|---|---|
| 牌 | 144 张：万、条、筒各 1–9 × 4，东南西北 × 4，中发白 × 4，春夏秋冬梅兰竹菊各 1 |
| 花 | 八张花牌 + 中发白共 20 张都算花，摸到立即亮出，从牌尾补一张；起手花从庄家开始依次补 |
| 起手 | 庄家 14 张先出牌，其余 13 张；出牌顺序按座位依次轮转。2 / 3 人桌规则相同，只是座位少 |
| 吃 | 只能吃上家打出的牌 |
| 碰、杠 | 任何一家打出的牌都能碰、明杠；自己摸齐四张可暗杠；已碰的刻子摸到第四张可加杠 |
| 吃碰后 | 这一手不能马上打出刚吃 / 碰进的同一种牌（手里只剩这种牌时除外）；吃碰后必须出牌，不能马上杠 |
| 抢牌优先级 | 胡 > 杠 / 碰 > 吃；几家同时能胡时一炮多响，都算胡，放炮者分别付给每个胡家 |
| 牌型 | 只认 4 副（顺子 / 刻子 / 杠）+ 1 对将，不带七对 |
| 杠开 | 开杠或补花后补进的那张牌自摸成胡 |
| 大吊车 | 吃、碰、杠满 4 副，手里只剩一张单吊成胡 |
| 门清 | 没有吃、碰、明杠、加杠（暗杠不影响） |
| 荒庄 | 牌摸完没人胡：本局不计分；下一局起加 1 荒番，连续荒庄累加，有人胡牌后清零 |
| 庄家 | 第一局房主坐庄，之后每局顺延到下一个座位（不连庄） |
| 暗牌 | 对局中别人的手牌只显示牌背（服务端只给张数），暗杠不显示牌面；一局结束只亮胡家的手牌和暗杠，荒庄谁都不亮 |

## 二、敲麻

| 项目 | 默认 |
|---|---|
| 底花 | 2 |
| 花数 | 每张花牌 1；万条筒：明杠（含加杠）1、暗杠 2、碰或刻子 0；东南西北：碰或暗刻 1、明杠 2、暗杠 3 |
| 起胡 | 看不含底花的花数：自摸至少 2 花，点炮至少 3 花 |
| 敲 | 必须先敲才能胡。出牌时选「敲」，打出这张后手牌必须已听牌 |
| 敲后 | 手牌锁定：摸到能胡的牌自动胡（有胡必胡）；摸到已碰那副的第四张自动加杠；其余摸到的牌自动打出。不能再吃、碰、明杠、暗杠；别人打出能胡的牌自动胡 |
| 无花果 | 除底花外一朵花都没有（没有花牌，也没有杠、风刻）时按 10 花计（含底花），并视为满足起胡 |
| 番（可叠加） | 清一色 2；混一色 1；碰碰胡 1；门清 1；杠开 1；大吊车 1；每个荒番 1 |
| 倍数 | （底花 + 花数）× 2^番；无花果时为 10 × 2^番 |

## 三、百搭

| 项目 | 默认 |
|---|---|
| 定百搭 | 开局从牌尾翻一张引导牌，亮出放在一边不再摸；它的下一张是百搭：数牌 9→1，风牌 东→南→西→北→东；翻到花（含中发白）时东风为百搭。同一种牌的 4 张都是百搭 |
| 用法 | 在手里时可替代任意非花牌；打出去、用于吃碰杠时按本身牌面算 |
| 胡牌 | 不用敲，也没有起胡花数。手里有百搭时只能自摸；手里没有百搭可以接炮 |
| 四百搭 | 手里集齐 4 张百搭立即胡，算自摸，2 番（不再叠加其他番，荒番照加） |
| 番（可叠加） | 无百搭 1；杠开 1；大吊车 1；门清 1；四百搭 2；每个荒番 1 |
| 花数 | 底花 1；每张花牌 1；风碰或风暗刻 1；明杠（含加杠）1；暗杠 2；风明杠 2；风暗杠 3；胡牌时手里每张百搭 1。用百搭凑成的风暗刻也算，系统按对胡牌者最有利的拆法计 |
| 倍数 | 花数 × 2^番（荒番已算在番里） |

## 四、付分（只记分）

| 情况 | 谁付 | 每人付多少 |
|---|---|---|
| 自摸 | 其余每一家 | 倍数（4 人桌胡家合计得 3 倍，3 人桌 2 倍，2 人桌 1 倍） |
| 点炮 | 放炮者一人 | 倍数 |
| 荒庄 | 无 | 0 |

- 底分 1。封顶由房主开房时设置：单个付分人每局最多付多少分，默认 128，可选不封顶。
- 结算显示每人的花数、番数（含番种明细）和本局得分；同一房间「再来一局」累计总分。

示例（4 人桌）：
- 敲麻自摸：3 张花牌 + 东风碰 1 = 4 花，加底花 2 共 6 花；混一色 1 番 → 6 × 2 = 12，三家各付 12，胡家 +36。
- 百搭点炮：2 张花牌 + 一个万字暗杠 2 + 底花 1 = 5 花；无百搭 1 + 门清 1 = 2 番 → 5 × 4 = 20，放炮者付 20。

## 五、节奏参数

| 项目 | 默认 |
|---|---|
| 真人出牌限时 | 20 秒，超时按电脑策略代打（能胡就胡，否则打最没用的牌），并进入托管；玩家任意操作即取消托管 |
| 吃碰杠胡响应限时 | 10 秒，超时视为「过」 |
| 电脑 / 托管 / 敲后自动出牌 | 约 1 秒后行动 |

## 六、已拍板

1. 百搭玩法里中发白也算花，和敲麻一致，共 20 张花。
2. 一炮多响：做。几家同时能胡都算胡，放炮者分别付给每个胡家。
3. 抢杠胡：不做。
4. 敲麻「无花果」：做。除底花外 0 花按 10 花计（含底花），并视为满足起胡。
5. 敲麻底花：2。
6. 2 / 3 人桌自摸：其余每家各付倍数，不额外补到 3 倍。
7. 荒番：有人胡后清零。
8. 庄家：每局顺延下家，不连庄。
9. 封顶：房主开房时设置，默认 128，可选不封顶。
